# Формат списков

Каждая запись занимает отдельную строку. Пустые строки и строки, начинающиеся
с `#` (после пробелов), игнорируются. Комментарии после значения не поддерживаются:
`#` внутри regex или URL сохраняется.

```text
# Домен вместе с поддоменами — сокращённая запись
example.com

# Точное имя; www. сохраняется
domain:www.example.org

# Домен вместе с поддоменами
domain_suffix:example.net

# Regex без кавычек; обратный слеш пишется один раз
domain_regex:^([a-z0-9-]+\.)?example\.com$

# Адрес или сеть, также можно без префикса
ip_cidr:192.0.2.0/24
2001:db8::1

# Внешние источники
srs:https://example.org/rules.srs
list:https://example.org/domains.txt
adguard:https://example.org/filter.txt
```

`list:` загружает текстовый список в этом же формате. `adguard:` загружает
отдельный фильтр AdGuard, который преобразуется sing-box в `*-adguard.srs`.
Старые `??`, `;;`, `||` остаются псевдонимами `srs:`, `list:`, `adguard:`.

У строки без префикса исторически удаляется начальное `www.`; у явных
`domain:` и `domain_suffix:` имя сохраняется. Домены и суффиксы приводятся к
нижнему регистру при нормализации. Regex сохраняет регистр и проверяется
движком sing-box. Пустое значение, неизвестный префикс, неверная IP-сеть
или regex останавливают сборку с указанием источника и номера строки.
